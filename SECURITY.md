# Security policy

Clearqo handles payments, so we take security reports seriously and appreciate responsible disclosure.

## Supported versions

| Version | Supported |
|---|---|
| 1.2.x | ✅ |
| < 1.2 | ❌ Please update |

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Report it privately instead:

1. Use GitHub's **[Report a vulnerability](https://github.com/NoobSaifii/clearqo-for-woocommerce/security/advisories/new)** button (Security tab), or
2. Email **[support@clearqo.com](mailto:support@clearqo.com)** with the subject `Security`.

Please include:

- the affected version,
- steps to reproduce or a proof of concept,
- the impact you expect (for example: an order marked paid without payment, or a wallet credited twice).

We will acknowledge your report within **72 hours** and keep you updated until it is fixed. Please give us reasonable time to release a fix before any public disclosure.

## Scope

- This plugin (`clearqo-for-woocommerce`).
- The Clearqo API and hosted payment pages at `clearqo.com`.

Out of scope: vulnerabilities in WordPress, WooCommerce, TeraWallet or Binance themselves. Please report those to their maintainers.
